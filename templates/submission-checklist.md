# Submission Checklist

The guide's own lists (§1, §7, §9) with the section-level requirements from §2–§8 merged in. Tick through it before you submit.

## Assembly & formatting
- [ ] Order: Title page → Abstract → Introduction → Method → Results → Discussion → References → Appendices
- [ ] Font: Times New Roman 12 pt, Arial 11 pt or Calibri 11 pt
- [ ] Double-spaced throughout, 1-inch (2.54 cm) margins
- [ ] Page numbers in the top-right header, starting on page 1
- [ ] Main body (Introduction to Discussion) is 1,800–2,200 words, and that count is on the title page
- [ ] Statistical symbols in italics (*M*, *SD*, *U*, *p*, *N*)

## Title page
- [ ] Descriptive title naming the operationalized IV and DV: bold, centered, upper half
- [ ] Group members' names and block
- [ ] AT Psychology, Singapore American School
- [ ] Submission month and year
- [ ] Word count of the main body

## Abstract
- [ ] Own page, bold centered **Abstract**, one paragraph, no indent, 120–150 words
- [ ] Aim + theory, participants + sampling, design + task, findings (*M*, *SD*, test, *p*), conclusion + application
- [ ] Written last; hypothesis and conclusion match the body

## Introduction
- [ ] One theory/model, cited, with key terms defined
- [ ] Anchor study: aim, method, findings with numbers, **and the link to the theory (why)**
- [ ] Why replicate + each modification + its **category** + core phenomenon preserved
- [ ] Aim, IV (both conditions operationalized), DV (exact measure), directional H₁, H₀

## Method
- [ ] Subheadings in order: Design → Participants → Materials → Procedure
- [ ] Design: what it controls + how its weakness was controlled
- [ ] Participants: **actual** N/age/gender, target population, sampling + reason, a controlled characteristic, ethics (consent, withdrawal, confidentiality, deception, debrief)
- [ ] Materials: each one → appendix; one self-made material + the EV it controls
- [ ] Procedure: chronological, timings, instructions, how the DV was recorded, pilot changes

## Results
- [ ] How the DV was scored
- [ ] Table 1 (central tendency + dispersion) + a sentence
- [ ] Figure 1: one graph, descriptive title, both axes labelled, undistorted, + a sentence
- [ ] Test + why + calculated value + critical value + *N* + H₀ accepted/rejected
- [ ] No interpretation, no raw data

## Discussion ([REVISED structure](../sources/discussion-structure-revised.md))
- [ ] ¶1 H₁ restated (same wording), supported or not, numbers (means + test), why, unexpected results/outliers and their effect
- [ ] ¶2 Comparison with the anchor study (direction + effect size); differences explained by modifications/sample/procedure; support/challenge/partly support the theory, cited
- [ ] ¶3 Two **specific** limitations of the design, materials or procedure
- [ ] ¶3 No bare "small sample size" or "lack of ecological validity"; if used, the specific mechanism is explained
- [ ] ¶3 At least one limitation is about **internal validity or reliability** (ceiling/floor, order effects, demand characteristics, inconsistent testing conditions)
- [ ] ¶3 Each limitation is linked to how it distorted **our** means, spread or outliers from ¶1
- [ ] ¶3 Each limitation has a **concrete procedural or material** fix
- [ ] ¶4 A specific conclusion supported by the data
- [ ] ¶4 Generalisation: **one real-world situation the task mirrors well** + **one where extra real-world factors would change the outcome**
- [ ] ¶4 **A justified real-world application/implication**
- [ ] ¶4 One direction for further research

## References & appendices
- [ ] References on a new page, APA 7, alphabetical, hanging indent, double-spaced
- [ ] Every in-text citation has a reference and vice versa (at least the anchor study + the theory source)
- [ ] Appendices A–E each on a new page with a bold centered label, and each referenced in the body
- [ ] Appendix E: every raw score + step-by-step calculations

## Language
- [ ] Formal, concise, third person (no I/we/they), past tense (hypotheses excepted)
- [ ] Correct terminology
- [ ] Paragraphs, with bullets only where allowed
- [ ] Hypothesis worded the same way in the Introduction, Discussion and Abstract
