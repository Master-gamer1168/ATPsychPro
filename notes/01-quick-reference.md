# 01 — Quick Reference (one-page cheat sheet)

Everything here comes from the [guide](../sources/guide-how-to-write-research-report.md). Facts about the [sample](../sources/sample-full-research-report.md) are measured from its .docx.

> ⚠️ **In-class rule (top of the guide):** *All writing will be done IN CLASS, using only your workbook and the data you collect as resources unless directly instructed by your teacher.*
> Use this repo to prepare **before** class: fill in the workbook, internalise the structure, and run your numbers. Don't plan on opening it while you write unless your teacher says you can.

## Word budget (main body = Introduction → Discussion)

| Section | Target | Sample report (approx.) |
|---|---|---|
| Introduction | 600–750 | ~710 |
| Method | 400–500 | ~530 (a little over) |
| Results | 200–300 + table + graph | ~200 |
| Discussion | 600–700 | ~655 |
| **Main body total** | **1,800–2,200** | **2,108 (stated on title page)** |
| Abstract | 120–150 (not counted) | 142 |

**Not counted:** title page, abstract, tables, figures, references, appendices.
The section targets add up to 1,800–2,250, so the **2,200 total cap** is the one that binds.

## Two orders

- **Writing order:** Introduction → Method → *(run study)* → Results → Discussion → **Abstract last**
- **Assembly order:** Title page (p. 1) → Abstract (p. 2) → Introduction (p. 3+) → Method → Results → Discussion → References → Appendices A–E

## Language rules (all sections)

1. Formal and **concise**. Long-winded descriptions lose marks.
2. **Third person.** Never *I / we / they*. Write "the researchers…" or "participants were…"
3. **Past tense.** The study has already happened. The one exception is H₁/H₀: they are predictions and use *will*, as in both the guide's template and the sample.
4. **Correct terminology** (independent measures design, operationalized, extraneous variable…).
5. **Paragraphs.** Bullets only where the guide allows them. In the body that means just the Aim/IV/DV/H₁/H₀ subheadings, which the sample still writes as sentences.

## Section skeleton

| # | Section | Must contain |
|---|---|---|
| 1 | **Title page** | Title naming the operationalized IV + DV (bold, centered, upper half) · names + block · "AT Psychology, Singapore American School" · month + year · main-body word count · page number 1 top-right |
| 2 | **Abstract** | One paragraph, no indent, bold centered label. Covers aim + theory → participants + sampling → design + task → findings (M, SD, test, value, p) → conclusion + application |
| 3 | **Introduction** | P1 theory/model (150–200) → P2 anchor study: aim, method, findings, **link to theory** (200–250) → P3 why replicate + each modification + its **category** (150–200) → P4 Aim, IV, DV, H₁ (directional), H₀ |
| 4 | **Method** | Subheadings in this order: **Design → Participants → Materials → Procedure** |
| 5 | **Results** | How DV was scored → Table (M, SD per condition) + sentence → Graph (title, labelled axes, undistorted) + sentence → test + why + calculated value + critical value + N + H₀ decision. **No interpretation. No raw data.** |
| 6 | **Discussion** | ¶1 hypothesis supported? + numbers + why + outliers → ¶2 vs anchor study (direction, size) and theory → ¶3 **two** limitations, each with effect + specific fix → ¶4 conclusion for the sample, generalisability, **real-world application**, further research |
| 7 | **References** | New page, APA 7, alphabetical, 0.5" hanging indent, double-spaced. Every citation ↔ reference |
| 8 | **Appendices** | A Materials · B Standardized instructions · C Consent form · D Debrief · E Raw data + calculations. Each on a new page, each referenced in the body |

## Formatting

- Times New Roman 12 / Arial 11 / Calibri 11. The sample uses Times New Roman 12.
- Double-spaced throughout, 1-inch (2.54 cm) margins
- Page numbers top-right, starting at 1 on the title page

## Mark-losers the guide calls out explicitly

- Leaving out the **link between the anchor study's findings and the theory** (Intro Part 2, point 4). "The one students most often leave out."
- Not naming the **modification category** for each change, or not showing that the change keeps the core phenomenon intact
- A hypothesis that **isn't worded the same** in the Introduction, Discussion and Abstract
- Interpreting in the Results, or putting raw data there
- An appendix that is never mentioned in the body
- No justified **real-world implication** in the Discussion
- Describing the *proposed* sample instead of the *actual* sample
