# 05 — Style, Terminology, APA & Formatting

## Report language (guide rules + examples)

| Rule | ✗ Avoid | ✓ Write |
|---|---|---|
| Third person | "We gave them a list…" | "Participants were given a list…" / "The researchers read…" |
| Past tense | "Participants will answer…" | "Participants answered…" |
| Hypotheses are the exception | | "…will recall significantly more…" (a prediction) |
| Formal + concise | "We basically wanted to see if…" | "The aim was to investigate…" |
| Terminology | "we split people up randomly" | "participants were randomly allocated to conditions" |
| Paragraphs | Bullet lists in Method/Discussion | Prose. Bullets only where the guide allows them |

The verbatim script in Appendix B is the one place where "we" is correct, because it is a quoted script.

## Terminology bank (as used in the guide and sample)

**Design and method:** laboratory experiment · independent measures design · repeated measures design · matched pairs design · random allocation · counterbalancing · standardized instructions / procedure · pilot study · partial replication · modification

**Variables:** independent variable (IV) · dependent variable (DV) · operationalized / operational definition · extraneous variable · confounding variable · controlled (… "so X could not affect/confound Y")

**Threats:** order effects (practice, fatigue) · carryover effects · participant variables · demand characteristics · expectancy effects · researcher bias

**Sampling:** target population · sample · opportunity sampling · random sampling · representative · generalizability

**Evaluation:** reliability · validity (internal, ecological) · generalizability · real-world application / implication

**Statistics:** descriptive statistics · measure of central tendency (mean) · measure of dispersion (standard deviation, range) · inferential statistics · one-tailed / directional · critical value · significant at *p* < .05 · null hypothesis accepted/rejected · ordinal data

**Ethics:** informed consent · right to withdraw · confidentiality / anonymity · deception · debriefing

**Theory (sample-specific):** Levels of Processing · shallow vs deep processing · structural / phonetic / semantic processing · encoding · episodic long-term memory · Multi-Store Model

## Modification categories (guide, for Introduction Part 3)

| Category | Typical reason |
|---|---|
| Ethical protection | Protects participants from distress, embarrassment or deception |
| Methodological control | Removes confounding variables, order effects or carryover effects |
| Construct adaptation and access | Replaces an inaccessible population or apparatus with a feasible analogue |
| Construct validity and measurement | Turns qualitative observations into a measurable DV |
| Feasibility and standardization | Fits the school timetable and gives every participant identical conditions |

The sample's pattern: *"First, [change] replaced [original] (category). Because [mechanism], [benefit]."*

## APA 7: in-text citations

| Type | Format | Example |
|---|---|---|
| Parenthetical, 1 author | (Author, Year) | (Lowry, 1998) |
| Parenthetical, 2 authors | (Author & Author, Year) | (Craik & Tulving, 1975) |
| 3+ authors | (Author et al., Year) | (Popov et al., 2017) |
| Narrative | Author and Author (Year) | "Craik and Tulving (1975) tested…". Use **"and"** in narrative and **"&"** inside brackets |
| Secondary source | (Original, Year, as cited in Secondary, Year) | (Craik & Lockhart, 1972, as cited in Popov et al., 2017). Only the secondary source goes in the reference list |
| No date / group author | (Name, n.d.) | (Random Word Generator, n.d.) |

## APA 7: reference list

Layout: new page · bold centered **References** · alphabetical by first author · **0.5" hanging indent** · double-spaced · no blank lines between entries · every citation ↔ reference.

Patterns from the sample:

- **Journal article:** Author, A. A., & Author, B. B. (Year). Title of article in sentence case. *Journal Name in Title Case, Volume*(Issue), pages. https://doi.org/…
  > Craik, F. I. M., & Tulving, E. (1975). Depth of processing and the retention of words in episodic memory. *Journal of Experimental Psychology: General, 104*(3), 268–294. https://doi.org/10.1037/0096-3445.104.3.268
- **Book (edition):** Author, A., Author, B., & Author, C. (Year). *Title in sentence case* (2nd ed.). Publisher.
  > Popov, A., Parker, L., & Seath, D. (2017). *Psychology course companion* (2nd ed.). Oxford University Press.
- **Website / tool, author known:** Author, A. (Year). *Title*. URL
  > Lowry, R. (1998). *VassarStats: Website for statistical computation*. http://vassarstats.net/
- **Website, group author = site name, no date:** Name. (n.d.). URL
  > Random Word Generator. (n.d.). https://randomwordgenerator.com/

Cite every tool you used to generate materials or compute statistics. The sample cites the word generator and both calculators.

## Page and heading formatting (from the guide + the sample's .docx)

| Element | Format |
|---|---|
| Font | Times New Roman 12 / Arial 11 / Calibri 11 |
| Spacing / margins | Double-spaced throughout, 1" (2.54 cm) margins |
| Page numbers | Top-right header, starting at 1 on the title page |
| Title page | Title bold + centered in the upper half, then names, block, course, month + year, word count (centered) |
| Abstract | New page, bold centered **Abstract**, one block paragraph, **no indent** |
| Start of Introduction | New page, **title repeated** bold + centered (no "Introduction" heading) |
| Level-1 headings | **Bold, centered**: Method, Results, Discussion, References, Appendix A… |
| Level-2 headings | **Bold, flush left**: Design, Participants, Materials, Procedure. Aim, Independent Variable… |
| Body paragraphs | 0.5" first-line indent |
| Statistical symbols | Italic: *M*, *SD*, *n*, *N*, *U*, *T*, *p*, *z*, *H*₁ |
| Numbers | Leading zero dropped for values that can't exceed 1: *p* < .05 (not 0.05) |
| Tables | **Table 1** (bold) → *Title in Italic Title Case* → table → *Note.* … |
| Figures | **Figure 1** (bold) → *Title in Italic Title Case* → image → *Note.* … |
| References | New page, 0.5" hanging indent |
| Appendices | Each on a new page: **Appendix A** (bold, centered) then **Title** (bold, centered) |
| Appendix tables/figures | Numbered with the letter: Table E1, Figure A1 |
